# Sway session keybinds (Alt = main modifier)

Matches Hyprland dotfiles except layout keys use native i3/Sway containers.

- `Alt+Return` — Terminal (kitty)
- `Alt+Shift+Return` — Terminal with fish `ub`
- `Alt+F12` — Dropdown terminal
- `Alt+F11` — Dropdown Spotify (splits with Discord when running)
- `Alt+Shift+Q` — Close window
- `Alt+D` — App launcher (rofi)
- `Alt+O` — File finder
- `Alt+C` — Browser
- `Alt+Ctrl+V` — Clipboard history
- `Alt+/` — Keybind cheat sheet
- `Alt+P` — Lock (swaylock)
- `Alt+Shift+P` — Power menu (l/s/e/h/r/Shift+s) — same as Hyprland
- `Alt+R` — Resize mode
- `Alt+Shift+C` / `Alt+Shift+R` — Reload Sway + waybar
- `Alt+Shift+E` — File manager (nemo)
- `Alt+M` — Toggle waybar
- `Alt+B` — Last workspace
- `Alt+1…0` — Workspaces
- `Alt+Ctrl+1…0` — Move window, stay
- `Alt+Shift+1…0` — Move window and follow
- `Alt+J/K/L/;` — Focus
- `Alt+Shift+J/K/L/;` — Move window
- `Alt+W` — Tabbed layout (focused container)
- `Alt+S` — Stacked layout
- `Alt+E` — Toggle split
- `Alt+Q` — Toggle split orientation
- `Alt+H` / `Alt+V` — Split horizontal / vertical
- `Alt+F` — Fullscreen
- `Alt+Ctrl+W` — Wallpaper picker
- `Alt+Shift+W` — Random wallpaper
- `Alt+Esc` — Game passthrough toggle
- `Alt+Ctrl+G` — Steam Link game mode
- `Alt+Ctrl+U` — Steam Link ungrab
- `Alt+X` — Display profiles (w/h/l) — same hotplug stack as Hyprland
- `Alt+Ctrl+M` — Pavucontrol
- `Print` — Screenshot

Waybar, wallpapers, dunst, nm-applet, display hotplug listener, and idle policy match the Hyprland session.
